Privacy Policy

Last updated: 17 November 2026

Aayush Clip Uploader is a personal tool used only by its owner, Aayush Shrestha.

What it receives from TikTok

  • Basic account information (display name and an account ID) to show which account is connected.
  • An access token that lets it upload videos to that account's inbox.

How it's stored

The token is stored only on the owner's private server and is used only to upload clips the owner selects. It is never sold, shared or used for advertising or tracking.

Other people's data

The tool does not collect data about other TikTok users or visitors.

Removing access

Access can be removed at any time in the TikTok app (Settings and privacy → Security and permissions → Apps and services), and the stored token is then deleted from the server.
